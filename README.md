# Training HQ — installable PWA

A locally stored workout tracker for the Upper A, Upper B, Lower + abs, Upper C, and optional Saturday tune-up schedule.

## Features
- Log working sets, loads, reps, and RIR; see recent logs and progression prompts.
- Mark weekly sessions complete and track progress.
- Save bodyweight, jump-height, sleep, and notes check-ins.
- Export/import a JSON backup and export set logs as CSV.
- Offline app shell after first successful load.

## Publish with GitHub Pages
1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
3. Wait for the Pages deployment. The URL will be `https://omarkhurram.github.io/Fitness-/`.
4. Open the URL in Safari on iPhone, tap **Share → Add to Home Screen**.

Workout data stays in browser storage on this device and is not synced. Export backups regularly. The app is not a medical device or a substitute for coaching.
